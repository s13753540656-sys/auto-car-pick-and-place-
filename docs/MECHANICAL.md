# 机械设计说明与改进方向

## 已有设计与分工

项目面向尖朝下放置的红色三角锥，自研夹爪采用下托合围式结构，安装在全向轮自动车上。夹爪机械结构为项目作者负责部分，控制与电控由团队另一组负责；不能把整车所有软硬件归为个人独立设计。

照片可直接观察到前部夹持结构、竖直导向、上部安装支架、底盘和走线；夹持面有浅色衬层。照片不能确认衬层材料、摩擦系数、准确尺寸、载荷能力或执行器型号。模型文件名可用于检索，不能单独证明实机当前使用了对应型号。

## 优先改进项

以下是待核实的设计建议，未修改原 CAD，也没有实机验证结果。优先级表示建议检查顺序，不表示已经确认存在故障。

| 优先级 | 检查方向 | 依据与应核实的问题 | 具体改进与验证方法 |
| --- | --- | --- | --- |
| P0 | 装配引用与主版本 | 存在两个整车装配名，实际引用及配置尚未打开核对 | 确认主装配、查失效引用、比较配置，生成经验证的 Pack and Go；记录软件版本 |
| P0 | 夹爪与目标适配 | 任务对象尖朝下，抓取依赖下托与闭合路径 | 用实物尺寸建立目标包络，检查进入、闭合、抬升、释放各阶段干涉；逐渐增加横向偏差与角度偏差，记录成功范围 |
| P0 | 全行程走线 | 照片可见多束线缆经过升降与转动结构周围 | 在断电手动确认允许行程后检查夹线、磨擦和拉紧位置；优化固定点与活动余量，复查传感器视野及工具空间 |
| P1 | 升降与支架稳定性 | 抓取后负载及偏心力会传至导向和支架 | 先测目标质量、重心与力臂，再核对导向支承、连接刚度及紧固；记录空载 / 负载动作的倾斜、卡滞与重复位置偏差 |
| P1 | 接触面与保持能力 | 夹持面有衬层，但材料与实际效果未知 | 记录材质、厚度、安装方式与磨损情况；比较原方案和单一变化后的掉落、表面损伤与释放稳定性 |
| P1 | 托持与定位结构 | 下托式抓取需要既能保持又能顺利释放 | 检查支撑面、导向边和退出路径，逐步验证慢速搬运、制动和放置；不以静止夹住代替动态保持测试 |
| P2 | 维护与装配效率 | 结构包含多种外购件和自制件 | 建立零件编号、标准件表、易损件清单及装拆步骤；检查紧固件可达性，减少维护时拆解无关部件 |

## 修改 CAD 前需要的输入

| 输入 | 当前状态 | 用途 |
| --- | --- | --- |
| 最终主装配、有效配置、原 SW 版本 | 待确认 | 建立唯一可复现的基线 |
| 三角锥外形尺寸、质量、重心、摆放公差 | 待测量 | 确认开口、托持和定位空间 |
| 执行器实际型号、供电、传动关系 | 待团队确认 | 核对闭合力、速度与允许负载 |
| 升降行程、末端允许位姿、机械限位 | 待测量 | 核对运动包络和碰撞 |
| 材料、打印方向、板厚、公差 | 待补充 | 评估加工与结构可靠性 |
| 底盘移动 / 制动工况 | 待确认 | 评估搬运时的动态载荷和保持能力 |

没有上述数据时，不直接指定齿比、舵机角度、夹紧力或板厚，也不承诺减重、承载或成功率提升。

## 推荐的比较方式

先固定同一目标、表面、摆放方式和控制参数，再一次改变一个机械因素。每次记录：模型版本、变化内容、目标偏差、尝试次数、成功次数、掉落位置、干涉 / 卡滞情况和循环耗时。原始数据与失败样例都应保留。

改动前先在 CAD 中核对运动与干涉，再按团队既有操作流程进行低速、低负载验证。控制参数应由对应负责人结合机械变化复核，不由照片或文件名推定。
